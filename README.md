# Frontend-features

React와 Express로 만든 프론트엔드 기능 모음입니다.

## 실행

1. `client`, `server` 폴더에서 `npm install`
2. `start.cmd` 실행
3. http://localhost:5173 접속

F12 Console에서 서버와 주고받는 패킷을 볼 수 있습니다.

## 카드

- 검색: 요청 취소, 자모 검색, 오타 제안
- 메인 스레드와 Worker: 화면 멈춤 비교
- 게시글: 무한 스크롤, 가상 목록, 관심
- 채팅: SSE 실시간 두 화면
